NFL Team Performance Analysis (Capstone Project)

This project analyzes NFL team performance from 2003–2023 to determine whether better offensive statistics lead to more wins. I cleaned and prepared the dataset using Python and pandas, then stored the data in a PostgreSQL database.

I designed a normalized database with multiple tables (teams, seasons, and offensive stats) and used SQL queries to analyze relationships between points, turnovers, and wins. The results showed that teams with stronger offensive performance generally had better records.

I also built a FastAPI application to access the data and created a Tableau dashboard to visualize trends in team performance.

Technologies Used: Python, pandas, PostgreSQL, SQL, FastAPI, Tableau
